# Using Single Cell ATACseq To Interpret Non-Coding Variants in ALS

Assay for transposase accessible chromatin (ATACseq) can be used to map open chromatin regions across the genome at single cell resolution. The technology has important limitations but enables mapping of candidate cis-regulatory elements, including promoters and enhancers, under both healthy and disease contexts. This practical will explore a single cell ATACseq dataset generated by Xiong, Cell, 2023 (DOI: 10.1016/j.cell.2023.08.040). This dataset covers major human brain cell types, and you will use it in nominating candidate causal variants in 2 ALS GWAS regions. To enable efficient and easy interaction with this data, it has been filtered and used to build a dedicated visualization session in the UCSC genome browser (https://genome.ucsc.edu/). Preparation of this session is described https://github.com/kkenna/browser_practical/blob/main/README.md 

If you need a reminder about what exactly ATACseq is, then see: https://www.youtube.com/watch?v=uuxpyhGNDsk 

The locations of all source files and the preparation of materials for the assignment is detailed below.

## Source data
* Source publication: Xiong, Cell, 2023; DOI: 10.1016/j.cell.2023.08.040
* Project website: https://compbio.mit.edu/ad_epigenome
* BigWig files (GRCh38): https://personal.broadinstitute.org/bjames/AD_snATAC/MFC/bigWig_TSS6/
```{bash}
curl -O https://hgdownload.soe.ucsc.edu/goldenPath/hg38/bigZips/hg38.chrom.sizes
curl -s https://personal.broadinstitute.org/bjames/AD_snATAC/MFC/bigWig_TSS6/ \
| grep -oE 'href="[^"]+\.bw"' \
| cut -d'"' -f2 \
| while read file
do
    curl -O https://personal.broadinstitute.org/bjames/AD_snATAC/MFC/bigWig_TSS6/$file
done
```

## Prep conda environment
```{bash}
conda config --add channels bioconda
conda create -n ucsc_tracks \
    ucsc-bedgraphtobigwig \
    ucsc-bigwigtobedgraph \
    ucsc-fetchchromsizes \
    ucsc-bedtobigbed \
    bedtools \
    coreutils \
    -y
```

## Filter BigWigs to genes of interest
```{bash}
conda activate ucsc_tracks
mkdir tracks
for i in nonAD*.bw 
   do 
      i=$(basename "${i%.bw}")
      bash bigWigFilter.sh $i.bw regions_50Kb_padding.GRCh38.bed hg38.chrom.sizes tracks/$i.flt.bw
   done
```
